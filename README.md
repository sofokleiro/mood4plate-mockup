<h1>mood4plate</h1> 

An interactive mockup for a mood-based AI food recommender app.

<h2>About</h2> 

Mood4Plate suggests recipes based on how you're feeling. Select your current mood and let the AI recommender match you with the perfect dish.

<h2>Features</h2>
<ul>
  <li>4 mood categories (Cozy, Energy, Social, Healthy)</li> 
  <li>AI recommendation simulation with match score</li>
  <li>Quick dietary filters (Vegan, High Protein, Under 20min)</li>
  <li>Save favourite recipes</li>
  <li>Dark mode support</li> 
</ul> 

<h2>How to Run</h2>

Open index.html in any browser — no setup or dependencies needed.
